# תוכנית אלול — הלכות שבת

עמוד לימוד לחודש אלול: חמישה שבועות, הסימנים, המחלוקות והמקורות.

**הקובץ נגזר ואינו נערך כאן.** הוא נבנה מתוך ריפו פרטי על ידי
`build/publish_elul.py`, וכל תיקון נעשה שם. עריכה ידנית של `index.html`
תימחק בפרסום הבא.

סיכום אינו מקור. העמוד הוא מפת יסודות ואינו תחליף ללימוד מן הספרים.
